# TLF stage 3 — programming augmentation

Treat the user-approved inventory and analysis/display shells as fixed. Add exactly one program specification per output identifier. Each specification must name its input datasets and copy every approved shell source variable into `adam_sources` as an explicit ADaM dataset-variable schema link. Do not invent datasets or variables that are absent from the approved shell or supplied ADaM metadata. Provide ordered language-neutral derivation steps plus reviewable R and SAS scaffold bodies. Scaffold bodies must not contain execution wrappers or claims of validation. Use conspicuous `TODO` expressions and review notes when required logic is missing. The application renders but never executes these programs.
