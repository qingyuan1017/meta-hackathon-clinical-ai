# SDTM stage 2 — variable and value-level mapping

Use the supplied stage-1 domain mapping as a fixed dataset-level plan. Map SDTMIG 3.4 variables with complete `sources` lineage and only minor per-variable derivation metadata. A direct variable has exactly one source; coalesce, lookup, transpose, aggregate, and derived variables retain every contributing source and its role. Assigned constants have no sources and must state the exact assignment. Each value-level metadata cell also retains its own source list. Use `value_level_metadata` when metadata or derivation changes under a where-clause. When a blank CRF is supplied, set `crf_source_label` to its exact label that should receive the aCRF annotation; otherwise leave it null. Return only the variable-mapping stage contract; the backend retains stage 1 unchanged. Put uncertainty in `unresolved_mappings`. Do not generate a `record_plan` or target-variable R/SAS expressions in this stage; record construction and executable code belong to rule augmentation. Use versioned CDISC Library metadata narrowly. A plausible mapping is not evidence of conformance.
