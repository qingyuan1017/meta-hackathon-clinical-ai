# SDTM stage 2 — variable and value-level mapping

Use the supplied stage-1 domain mapping as a fixed dataset-level plan. For every target domain, map source variables to SDTMIG 3.4 variables with source dataset and field traceability, origin, mapping expression, controlled-term context, and value-level metadata. Use `value_level_metadata` when metadata or derivation changes under a where-clause. Set `crf_source_label` to the exact blank-CRF label that should receive the aCRF annotation; leave it null when no reliable label exists. Return only the variable-mapping stage contract; the backend retains stage 1 unchanged. Put uncertainty in `unresolved_mappings`. Do not generate R or SAS expressions in this stage. Use versioned CDISC Library metadata narrowly. A plausible mapping is not evidence of conformance.
