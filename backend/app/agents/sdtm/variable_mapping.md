# SDTM stage 2 — variable and value-level mapping

Use the supplied stage-1 domain mapping as a fixed dataset-level plan. For every target domain, map source variables to SDTMIG 3.4 variables with source dataset and field traceability where a direct single-field source exists, plus origin, mapping expression, controlled-term context, and value-level metadata. Assigned constants and derived variables do not need a raw source: set both `source_dataset` and `source_field` to null, use an Assigned, Derived, Protocol, System, or Sponsor origin, and state the exact assignment or derivation in `mapping_expression`. Never put `Assigned`, `Derived`, an expression, or another origin label in `source_dataset`. Use `value_level_metadata` when metadata or derivation changes under a where-clause. When a blank CRF is supplied, set `crf_source_label` to its exact label that should receive the aCRF annotation; otherwise leave it null. Return only the variable-mapping stage contract; the backend retains stage 1 unchanged. Put uncertainty in `unresolved_mappings`. Do not generate R or SAS expressions in this stage. Use versioned CDISC Library metadata narrowly. A plausible mapping is not evidence of conformance.
