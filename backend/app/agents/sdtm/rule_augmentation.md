# SDTM stage 3 — rule augmentation

Treat the supplied domain and variable mappings as fixed inputs. Add exactly one `domain_rule_augmentations` entry for every target domain and exactly one `rule_augmentations` entry for every target domain-variable pair. A domain rule must cover all mapped source datasets and provide the complete R input expression and SAS SET/MERGE statement needed before variable assignment, including split, merge, and existing-SDTM cases. A variable rule must identify source dependencies, explain the language-neutral logic, and provide R and SAS right-hand-side expressions without assignment syntax or trailing delimiters. Expressions are inserted into generated draft programs but are never executed. Use explicit missing-value handling and controlled-term recoding when supported; otherwise retain a conspicuous TODO expression and add a review note or unresolved mapping. Return only the rule-augmentation stage contract; the backend retains stages 1 and 2 unchanged. This is draft implementation metadata, not evidence of SDTM conformance.
